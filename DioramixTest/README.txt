DIORAMIX PRESENTATION - WEB HOSTING
====================================

HOW TO USE:
1. Upload all files to a web server (GitHub Pages, Netlify, etc.)
2. Open index.html in a browser

REQUIREMENTS:
- Web server required (won't work by double-clicking HTML file)
- Internet connection required for first load (libraries cached after)

CONTENTS:
- index.html (interactive 3D presentation)
- assets/ (3D models: PLY, OBJ, GLB files + OBJ materials/textures)

HOSTING OPTIONS:
- GitHub Pages (free): https://pages.github.com/
- Netlify (free): https://www.netlify.com/
- Vercel (free): https://vercel.com/
- Any web server (Apache, Nginx, etc.)

CREATED WITH: Dioramix Presentation Editor
