# International Education WebXR

Copy the contents of this folder to the root of a GitHub repository. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Open the resulting HTTPS address on a desktop, mobile device, or Quest browser. No build or server is required after publishing.

Drag to look, use WASD or arrows to move, and Q/E to change height. On touch devices, drag and use the on-screen arrows. Enter VR appears when the browser reports immersive VR support; thumbsticks provide basic movement. HTTPS is required for WebXR. The editor is intended for desktop.

The Editor stores named positions in the current browser. Export JSON to transfer or back up positions. To make exported positions the defaults for all users, replace `data/positions.json` in the repository with the export. Changes in the editor cannot write directly to GitHub. Rotation is in degrees about Y; position and rotation use world coordinates. `playerStart` sets the initial camera position and yaw. Existing local data overrides the defaults on that browser.

The office uses the smaller original PLY, with a fixed -90° rotation about X to make its Z axis vertical. Do not change this transform after saving positions. The initial viewpoint is an estimate and can be refined with the editor. The site uses Spark 2.4.0 and Three.js 0.180.0, bundled locally. Quest and mobile performance depend on the device; no collision detection is provided.

Phase 2 adds the animated advisor and one CPT question with audio, retry, congratulations, and restart. Use the circular joystick on mobile. Save a position named questionPanel to adjust the world panel. Advisor placement supports the supplied AvisorPosition name; its saved Y is interpreted as eye height (feet are 1.6 units below). The character is normalized to 1.75 units tall. Phase 2 uses a separate localStorage key so Phase 1 data remains intact. Question content is at the top of assets/experience.js. Rebuild from the project directory using node webxr-dev/build.cjs after editing webxr-dev/site. Quest and mobile require manual testing. The original Phase 1 PLY remains in use.

Scene editing: open Editor, choose Advisor or Question / answer panel, then use Move (W), Rotate (E), or Scale (R). Drag the colored gizmo or change numeric fields. Values save automatically; Reset object restores the published defaults. Export JSON includes position, rotationY, rotation [X,Y,Z] in degrees, and scale [X,Y,Z]. Replace data/positions.json with the export to publish defaults. Advisor legacy position Y retains the existing +1.6 eye-height convention; scene numeric fields show the actual parent position. The panel's saved rotation is a billboard offset during gameplay. Add future objects through getEditableObjects() in assets/experience.js.

Advisor update: assets/advisor.glb is student.glb with Idle and Talking clips retargeted offline from Neutral Idle.fbx and Talking.fbx. Bone translations are fixed to preserve proportions and eliminate root travel. Both clips loop and crossfade over 0.25 seconds. Advisor speech alone drives mouthOpen on the head and teeth using a Web Audio volume analyser. Speech playback, body transitions, mouth reset, audio errors, and retry are coordinated in assets/advisor-speech.js. Fine-tune the noise threshold and gain there if needed. Mobile and Quest audio/animation quality require manual device review. Original source assets are preserved.

Arm retarget correction: source Mixamo T-pose arm segments are now aligned against the student model's lowered-arm bind pose before baking animation rotations. Target bone roll and bone lengths are preserved, and quaternion signs remain continuous. Representative Idle and Talking poses were visually checked after re-importing the exported GLB.
