# Exploring eLearning Tools portfolio

This folder is a complete static site. Upload its contents to the root of a GitHub Pages repository and choose **Deploy from a branch → root** in the repository's Pages settings.

## Add a weekly artifact

1. Open `index.html` and find the matching `<article id="week-0X">`.
2. Replace `Coming soon` with a short status such as `Published`.
3. Add a link, reflection paragraph, or embed below the status inside that article. Keep the week heading link and `id` unchanged so keyboard navigation and direct links keep working.
4. For an embed, use the commented example in Week 2. Give every iframe a descriptive `title` and use an `https://` embed URL.

Edit `styles.css` only when you want to change the shared visual system. `DESIGN.md` records that system. There are no packages to install or commands to run.
